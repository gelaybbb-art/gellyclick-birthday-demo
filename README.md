# GellyClick Studio — Little links, big feelings

A redesigned landing page for the GellyClick digital greeting website business. Includes a warm editorial brand identity, a colorful sample collection, responsive navigation, project links, and a small custom-request message builder.

- Monthsary: `https://gelaybbb-art.github.io/gellyclick-monthsary/`
- Custom occasion: directs visitors to the request section on this page.

## Publish with GitHub Pages
1. Create or open the repository for your GellyClick main website.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root, replacing the old homepage files.
3. Commit the changes to `main`.
4. Confirm **Settings → Pages** uses `main` and `/(root)`.
5. Wait for the deployment under the **Actions** tab to complete.

For a repository named `gellyclick-birthday-demo`, the expected URL is:
`https://gelaybbb-art.github.io/gellyclick-birthday-demo/`

## Before sharing with customers
- Check that the three sample pages are published and update any link if a repository uses a different name.
- The “Email your idea” control opens the visitor's email app with a prefilled inquiry to `gellyclick@gmail.com`. Confirm that this Gmail address is created and belongs to you before publishing.
- Sample preview images load from Unsplash; Google Fonts and images need an internet connection.
- This is a static website: no backend or API key is required.
