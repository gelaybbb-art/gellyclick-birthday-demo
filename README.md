# GellyClick Birthday Demo
**Suggested GitHub repository name:** `gellyclick-birthday-demo`

## Files
- `index.html` — landing page and three sample demos
- `style.css` — responsive styling
- `script.js` — mobile navigation and interactive sample previews

## Publish with GitHub Pages
1. Create a GitHub repository named `gellyclick-birthday-demo`.
2. Upload these three files to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for the published link to appear.

## Before sharing with customers
- Replace `https://m.me/` in `index.html` with your actual Facebook Page/Messenger link.
- Change the sample starting price if needed.
- Sample names are fictional. Photos are illustrative remote Unsplash stock images; use licensed or customer-provided photos for actual orders.
- This is a static website. It needs no backend or API key.
